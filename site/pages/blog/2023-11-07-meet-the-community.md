A starter is easier to use when you know where to turn for help. Herbie is a small
project, but there are a few good places to look.

## The documentation

The {{ link_page('https://herbie.tebe.ch', 'Herbie website', {target: '_blank'}) }}
collects guides and reference material. Start there for configuration options and
plugin details.

## The source code

Everything is on {{ link_page('https://github.com/getherbie/herbie', 'GitHub', {target: '_blank'}) }}.
Reading the bundled example site is often faster than searching for an answer: it shows
real templates, plugins and local extensions.

## This starter

The {{ link_page('https://github.com/getherbie/start-website', 'start-website repository', {target: '_blank'}) }}
is where this example lives. Issues and pull requests are welcome — especially if you
found a placeholder that should say something useful.

## Contributing content

Every post here is a Markdown file. If you want to add an example, copy an existing
post, change the front matter and write your text. The
